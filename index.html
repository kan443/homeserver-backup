homeserver-backup

個人が所有するサーバのデータを、所有者本人の Google ドライブへバックアップするための、個人利用専用のツールです。

できること

自宅で稼働している小規模なサーバ上のデータベースや設定ファイルを、 暗号化したうえで所有者自身の Google ドライブへ定期的に保存します。 バックアップの作成と復元にのみ使用します。

  • バックアップの保存先として Google ドライブを利用します
  • 保存するデータは、保存前に restic によって暗号化されます
  • Google ドライブとの通信には rclone を使用します

アクセスする範囲

このアプリが要求する権限は drive.file のみです。 このアプリ自身が作成したファイルにしかアクセスできません。 利用者が以前から Google ドライブに保存している他のファイルを、 参照することも変更することもできません。

利用者

このアプリは作成者本人だけが使用します。一般に配布・提供しているものではなく、 他の利用者を受け入れる予定もありません。

データの取り扱い

Google ユーザーデータの取得・利用・保存・共有については プライバシーポリシーに記載しています。

Summary (English)

homeserver-backup is a personal-use tool that stores encrypted backups of the author's own home server onto the author's own Google Drive. It requests only the drive.file scope, so it can access only the files it creates itself and cannot read or modify any other file in the user's Drive. It is used solely by its author and is not distributed to other users. See the Privacy Policy for details on data handling.
